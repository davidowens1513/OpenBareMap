BAREGPS TRACK EDITOR - ANDROID BUNDLE
Version 0.1.1 | 6 November 2026

1. WHAT IS INCLUDED

BareGPS-Track-Editor-0.1.1.apk is the installable Android app.
This guide and SHA256SUMS.txt are included in the Android ZIP bundle.

This is a development build, signed with the project's development key.
It is supplied directly by Apps by Onzy rather than through Google Play.

2. BEFORE YOU INSTALL

Use an Android phone or tablet running Android 7.0 or later, with a current
Android System WebView or Chrome. The APK is approximately 5 MB.
Internet access is needed for OpenTopoMap tiles and optional terrain heights.
Importing, editing and exporting GPX files work without a map connection.
Location permission is not required to edit tracks.

3. INSTALL THE APK

Download the .apk directly, or unzip the Android Bundle and open the APK.
In Files / My Files / Downloads, tap BareGPS-Track-Editor-0.1.1.apk.
If Android asks, allow installation from the browser or Files app you used,
then return to the APK and choose Install. Open BareGPS Track Editor.
You can turn off that install permission again afterwards.

Use your device's normal security checks. If installation is blocked,
check the source of the file and the exact message rather than bypassing it.

4. TRY THE IRISH EXAMPLES

Tap Explore with sample tracks, or Irish samples in the tracks panel.
The illustrative examples are Glendalough Upper Lake and Spinc ridge in
County Wicklow. They demonstrate editing and are not navigation directions.

5. OPEN AND EDIT YOUR TRACKS

Tap Open files and select one or more GPX files from the system Files picker.
Select a track, then drag the A and B handles on the map or use the sliders
to choose a section. Distance, ascent, descent and elevation update live.
Use Split to make two new tracks, or Reverse to change a track's direction.
Start a joined route and append further sections in walking order.
You can choose a colour for each track and expand or collapse the map.

Dashed connections between separated sections count toward distance and
ascent because they must be walked. Their initial ascent uses endpoint
heights and is estimated. Fetch gap terrain to include intermediate hills
and valleys. Terrain sampling uses straight connections, not trail routing.

6. SAVE YOUR RESULT

Save section exports the chosen A-B portion. Save route exports the joined
route. Choose a destination in Files and save the GPX there.

Saved in the header means the workspace is saved on this device. It does
not mean a GPX file has been exported. Export tracks you want to keep.
Uninstalling or clearing the app's data can remove the local workspace.

7. UPDATING OR TROUBLESHOOTING

For updates signed with the same project key, installing the newer APK
normally keeps the workspace. Export important GPX files before an update.
If Android reports a conflicting signature, export your tracks before
considering removal of an earlier differently signed copy.

If a file fails to import, choose a valid GPX track or route with at least
two points. The limit is 15 MB per file. An invalid file is reported by name.
If the map does not load, check the connection and use Retry; file editing
and export remain available. Missing GPX heights produce partial ascent.
