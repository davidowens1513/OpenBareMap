INSTALL OR UPDATE
BareGPS-Route-Planner-0.2.11.apk is the non-debuggable release-signed app.
The ZIP contains the same APK, installation instructions and checksum.
Download the APK or extract the ZIP, then open it in Files / My Files.
Follow Android's normal installation and security prompts. Revoke any temporary
browser/Files installation permission afterwards if desired. Do not disable
security protections to force installation.

Updates from the permanent release identity install in place. Older debug-signed
development apps use a different identity: export important routes before
uninstalling them, because uninstalling removes the entire local workspace.
Then install the release APK and import the exported routes. GPX export is
not a complete project backup. Keep the permanent signing identity for updates.

USING BAREGPS ROUTE PLANNER

CREATE NEW
Tap the map to add points. Insert point adds between neighbours, then returns
to Add points. Drag numbered markers, delete a selected point, or Close loop.
Lines are straight and do not automatically follow paths. Name the route in
its card. Fetch Terrain estimates heights; Save Route fetches terrain still
needed before export, or offers an explicit Save without terrain after failure.

Open in Edit copies the drawing and available heights into Input Tracks and
selects the copy. The Create draft stays unchanged. This does not fetch terrain,
add a plan entry or confirm output. The two copies are independent.

EDIT EXISTING
Open GPX files and select an input. Use Add, Insert, Delete and Close loop,
or Trim before/after and Reverse. A trim retains the selected point and at
least two points overall. Deletion, removal, trimming and clearing ask for
confirmation. Cancel keeps data unchanged; Undo can restore confirmed edits.

The pencil immediately left of each input's colour circle opens Rename Input
Track. Names change only the workspace copy; original filenames and existing
plan snapshots remain unchanged. Each input also has a colour control and bin.

Editing handles default to every 20 points, including endpoints, with at most
200 shown at once. Settings changes spacing without removing underlying points.
Moving handles tapers through dense points; changed points lose stale heights
and times. Trim preserves retained metadata. Fetch Terrain refreshes the input.

Add to Route Plan is the full-width button below editing tools. Route Plan is
below Input Tracks. Add copies the whole input; later edits do not change plan
snapshots. Select a row to reorder, remove or explicitly replace it with the
current input. Confirm Route alone builds/updates the output card, fetching
missing heights and connections while retaining valid recorded heights. Cancel
or failure keeps the previous output. Confirm without terrain explicitly makes
an incomplete result. There is no Preview button in the Route Plan dialog.

The confirmed output defaults to Edited Route. Its Route Card has an editable
name and Preview. Use the x Preview Mode control at the map's upper left to
return to the input. Clear route and Save Route are beneath the reduced card.
Clearing the output/plan preserves inputs and the Create draft. There is no
separate input export button.

ROUTE CARDS, PROFILE AND SHARING
Native compact cards show Point, coordinates, Height and Distance; enabling
point naming swaps Name for compact Distance. Web cards show all measures
without expansion, with Create bins at the far right. Expanded web tables
fill the available width. Expand scrolls the complete card with only Share
Text and Share PDF as footer actions, plus collapse at the top. Expansion and
sharing never fetch terrain. Native sharing uses system sheets; browser
fallbacks allow text copying or PDF download. All points are exported.

The taller elevation graph is blank until heights are available. Its status
below identifies Terrain not fetched, Terrain up to date, Terrain needs refresh
or Terrain incomplete. Estimates and partial ascent are labelled; missing
height is not zero. Terrain progress x, Cancel and Escape request cancellation
without silently replacing the route.

SETTINGS AND GUIDE
The cog opens separated Grid references, Created Route Colour, Allow Point
Naming and Input Track Editing sections. Naming defaults off and hiding names
does not erase them. Preferences are kept on the device. Grid systems include
Lat/Long (WGS84), Irish Grid, British Grid, ITM, MGRS, UTM and USNG. GPX always
uses WGS84; regional conversions are approximate, not surveying measurements.

SCOPE AND SAVED WORK
This is a walking-route planner, not live navigation, activity recording or
emergency assistance. Check access and walkable ground independently. There
is no downloadable offline map pack. Maps and terrain need internet; relevant
coordinates are sent to map/terrain providers. Service and terrain-job limits
apply. Recorded height noise can inflate ascent.

GPX exports preserve planned geometry and supported point data, not every
activity extension, standalone waypoint, description or original segment
boundary. Other apps may draw continuous connections. Retained timestamps can
run backwards after Reverse or jump between joined recordings. Keep originals.

Saved on device means workspace recovery, not a complete project backup or
cloud sync. Export important routes before uninstalling or clearing app/browser
data. Fresh installation removes the workspace. Undo history does not survive
reopening. The original file changes only if you choose to overwrite it.
