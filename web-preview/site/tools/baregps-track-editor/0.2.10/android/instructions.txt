BAREGPS ROUTE PLANNER — ANDROID
Version 0.2.10 build 42 (release signed) | 9 November 2026

INSTALL OR UPDATE

BareGPS-Route-Planner-0.2.10.apk is the installable release-signed Android app.
The ZIP bundle contains the same APK, instructions and checksum. Download the
APK directly, or extract the bundle and open the APK in Files / My Files.

If Android asks, allow installation from the browser or Files app you used.
You can disable that installation permission again afterwards. Follow your
device's normal security checks. If installation is blocked, do not disable
security protections to force it.

USING BAREGPS ROUTE PLANNER

CREATE NEW

Add points in walking order on the map. The four bordered buttons are Add
points, Insert point, Delete point and Close loop. Tap a numbered marker to
select it for deletion, or drag it to move. Lines are straight and do not
follow paths automatically. The default route name is Created Route.

Fetch Terrain on the reduced Route Card manually previews heights. Save Route
also fetches any terrain still needed before exporting, and reuses terrain
already fetched. Expanding or sharing the card never starts a fetch. Failed
saving offers Retry terrain and save, or explicit Save without terrain.
Cancel preserves the route. Export defaults to Created Route.gpx.

EDIT EXISTING

Open GPX file(s), then choose an input in Input Tracks. The whole input is
editable immediately; there are no A-B sections or sliders. The map toolbar
matches Create. Below it, four equal-width buttons offer Trim before,
Trim after, Reverse and Fetch Terrain. A thin strip shows the selected point.
Trim retains that point and removes all points on the chosen side, keeping
at least two points. Undo restores edits. Each input row has its own colour
circle beside the bin. The bin removes a workspace input, not its source file.

Editing handles default to every 20 points, including the first and last.
Settings > Input Track Editing changes spacing without removing points.
Up to 200 handles appear at once; zoom/pan or tap the line to reveal others.
Moving handles tapers the movement through intervening dense points.
Moved points lose stale heights/times; trimming keeps retained metadata.
Fetch Terrain under the map refreshes missing or invalidated input heights.

Add to Route Plan copies the whole edited input. Route Plan reopens the list;
select rows to Move up, Move down or Remove. Inputs and plan copies remain
independent. Replace selected track with current input explicitly updates a
saved row. Once all listed inputs have been added, the input selection clears.

Confirm Route fetches missing heights, edited legs and new connections from
Open Topo Data, preserving recorded heights. Only completion updates the
Route Card; complete terrain is reused for an unchanged plan. Fetch failure
keeps the plan and previous route intact. Retry terrain tries again; Back to
Route Plan returns to planning; Confirm without terrain explicitly builds an
incomplete route with partial ascent clearly marked. Cancel keeps prior data.

The confirmed output defaults to Edited Route. Its Route Card has Rename and
Preview, with Clear route and Save Route underneath. There is no bottom Fetch
Terrain in Edit. Save Route exports the confirmed output as Edited Route.gpx.
Clear asks before clearing the output and plan; input tracks and Create remain.
There is no separate input export button.

ROUTE CARDS, PROFILES AND SHARING

Reduced cards scroll after six point rows. Expand for distance, cumulative
distance, ascent and cumulative ascent; Share Text and Share PDF stay visible.
Both share the complete route, including offscreen rows. Heights and ascent
are estimates, and incomplete terrain is labelled. The elevation profile has
the same reserved size before and after loading, now one third shorter.

SETTINGS, COLOUR AND GRID REFERENCES

The cog opens Grid references, Created Route Colour, Allow Point Naming and
Input Track Editing. Naming is off by default. On displays editable names
(up to 10 characters) instead of Distance in the reduced card; [Name] marks
an empty name. Off hides names without deleting them. Preferences persist.

New imported tracks without a stored colour start red, blue and pink; new
joined routes start green. Input colours are adjustable in Input Tracks.
The Create colour is in Settings. Colour changes preserve terrain.

Available Systems retains full descriptions for Lat/Long (WGS84), Irish Grid,
British Grid, ITM, MGRS, UTM and USNG. Cards use shorter headings. The choice
updates cards, sharing and map-centre readouts; GPX always uses WGS84.
Regional grid conversions are approximate and precision is not GPS accuracy.

MAPS, LOCATION, WARNINGS AND DATA

The location button requests one position fix and shows an accuracy circle.
It never adds a point or records in the background. Map tiles and terrain
need internet access. Terrain fetching sends relevant coordinates to Open
Topo Data. Map failures do not prevent editing; Retry reloads tiles and X
dismisses warnings clear of the position button. Warnings clear on recovery.
Routine success banners are suppressed; warnings and errors remain visible.

Saved on device means workspace recovery, not an exported GPX backup. Export
important routes before uninstalling or clearing app data. Create and Edit
have separate drafts, maps and Undo histories. To edit a Create route, save
its GPX, then open it in Edit. Undo history does not survive reopening.
